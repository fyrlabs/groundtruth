## Methodology

This report was produced by the Groundtruth multi-agent pipeline:

1. **Discovery** — web search surfaces new repo candidates
2. **Triage** — maturity, novelty, and duplication gates filter candidates
3. **Analysis** — deep code reading: tech stack, architecture, capabilities, claim extraction
4. **Verification (parallel)** — three independent agents verify claims from code, community sources, and compatibility evidence
5. **Online spot-check** — targeted web verification for changed or new repos
6. **Reconciliation** — meta-reviewer synthesizes all agent outputs, resolves contradictions, assigns final confidence tiers

**What "code-verified" means**: The claim was confirmed by reading actual source files — not README text, not comments, but implementation code, manifest files, test files, or license files.

**Limitations**: Benchmarks claimed by repos themselves (GAIA score, FinanceBench %) cannot be independently reproduced by this pipeline — they are marked ⚠️ self-reported unless an independent third-party source confirms them. Live data (GitHub stars, last commit date) reflects the moment of analysis and may be stale.
